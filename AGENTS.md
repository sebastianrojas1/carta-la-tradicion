# Reglas de trabajo

- Editar unicamente los archivos indicados por el usuario.
- Agregar comentarios breves y claros en espanol para alguien que aprende JavaScript.
- Explicar el proposito o la razon del codigo, evitando comentar cada linea.
- No cambiar el comportamiento cuando el pedido sea solamente agregar notas.
- Mantener cambios pequenos y faciles de revisar.
- No instalar dependencias, borrar o renombrar archivos, hacer commits ni push sin autorizacion explicita.
- Al finalizar, informar que archivos cambiaron y como se verificaron.
- Mantener la mentoria: consignas, practica propia y revision. Dar codigo completo cuando se solicite.
