# Carta digital de La Tradicion

Carta web estatica de sandwiches y postres para consultar desde un celular.

## Vista local

Abrir `index.html` en un navegador. No requiere dependencias.

## Mantenimiento

El contenido, CSS y JavaScript estan en `index.html`. Las fotos estan en `imagenes/`. Actualizar las rutas en CSS y en `data-image-src` al cambiar fotos, respetando nombres y mayusculas.

## Antes de entregar

- Confirmar contenido y permiso de uso de fotos con el comercio. Faltan precios.
- Probar en celulares y comprobar apertura y cierre de fotos.
- Optimizar imagenes: los fondos se descargan al abrir la carta.
- Publicar con HTTPS y generar el QR con la direccion definitiva.
- Probar el QR con datos moviles. Mantener la direccion al actualizar.

## Repositorio

Pendiente inicializar Git y publicar en GitHub con autorizacion del propietario. No incluir credenciales ni datos privados.
